## Project Description

Princess Fashion Store is a responsive website created for a local
fashion store. The website presents information about the business,
its mission, vision, values, clothing categories and contact details.

# Goals and Ojectives
  Our goal is to follow all new trends and be able to accommodate each and everyone's style of dressing.
  Our mission is to provide our customers with the best quality clothes at affordable prices.
  Our vision is to be the leading clothing store in the area, known for our exceptional customer service and wide selection of fashionable clothing.

## Features

- Responsive navigation
- About Us section
- Mission section
- Vision section
- Values section
- Clothing categories
- Contact information
- Contact enquiry form
- Social media links
- Responsive desktop, tablet and mobile layouts
- Accessibility improvements
- SEO metadata
- External CSS stylesheet
