# Princess Fashion Store

## Project Description

Princess Fashion Store is a responsive website created for a local
fashion store. The website presents information about the business,
its mission, vision, values, clothing categories and contact details.

## Features

- Responsive navigation
- About Us section
- Mission section
- Vision section
- Values section
- Clothing categories
- Contact information
- Contact enquiry form
- Social media links
- Responsive desktop, tablet and mobile layouts
- Accessibility improvements
- SEO metadata
- External CSS stylesheet

## Technologies Used

- HTML5
- CSS3
- Visual Studio Code
- Git
- GitHub
